# ReparaCampus

Prototipo para gestionar incidencias de infraestructura de la Universidad Simón Bolívar.
Segundo examen práctico de Ingeniería de Software I: *Spec-Driven Development con IA*.

> Todos los datos y cuentas de este repositorio son ficticios.

## Estado

El repositorio sigue el hilo **Requisito → Historia → SPEC → Código → Prueba**.
Las especificaciones se versionan y revisan antes de programar cada funcionalidad.

| Etapa | Ubicación | Estado |
|---|---|---|
| Problema, alcance, preguntas y supuestos | `specs/00-problema-y-alcance.md` | En revisión |
| SPECS S01–S05 (especificación, plan y tareas) | `specs/S0x-*/` | En revisión |
| Diseño (componentes, datos, UML, decisión) | `docs/diseno/` | En revisión |
| Implementación | `app/` | Pendiente |
| Pruebas automatizadas | `tests/` | Pendiente |

## Ruta tecnológica

Python + Flask + SQLite en el servidor, HTML/CSS/JavaScript con plantillas Jinja en la interfaz y pytest para las pruebas.
Las versiones exactas, la instalación, el seed, las cuentas ficticias y los comandos de prueba se documentarán aquí al integrar la implementación.
